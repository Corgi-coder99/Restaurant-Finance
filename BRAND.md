# Bếp Finance visual identity

Bếp Nhỏ is the illustrated rice-cooker mascot. The web-optimized mascot and app icons are in `dist/assets/`. The interface uses forest green (`#174B40`), ivory, sage, and Be Vietnam Pro with a sans-serif fallback.

The guided tour introduces branch selection, KPIs, costs, simulations, and sample transactions. Users can skip or reopen it. Completion is stored locally under `bep-tour-v2`. The mascot provides fixed guidance.

The mobile dashboard groups the main views in a bottom navigation bar and presents branch details as cards. The cashier workspace uses prominent table states, a running total, payment review, and separate receipt actions.
